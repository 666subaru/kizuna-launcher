## 🇬🇧 English

**Kizuna** (絆 — "bond") is a free, open-source game translation launcher for Windows. Pick a game, press **Translate**, play it in your language. That's the whole tutorial.

Thousands of great games never get localized. Existing tools are powerful but manual: learn the tool, find the engine, extract, patch, pray. Kizuna's philosophy is different: **the user never chooses a method — the system detects and applies it.**

### What makes it different

| | |
|---|---|
| 🖱️ **One click, zero setup** | Auto-detects your installed games (Steam, Epic, standalone) and their engines. No configs, no plugins to hunt down. |
| 🧩 **6+ engines supported** | RPG Maker MV/MZ, Ren'Py, KiriKiri/KiriKiriZ (incl. compiled PSB scenarios), Unity, Unreal (.locres, .int, UE3 .upk), and more coming. |
| 🖼️ **Translates images too** | Text baked into menus, HUDs and buttons? Kizuna OCRs the image, erases the original text, redraws it in your language, and re-encrypts the file. Almost no other tool does this — automatically, in the same one click. |
| 🧠 **Embedded local AI fallback** | When online translation fails or refuses a line, a bundled local model (GPU-accelerated) picks it up. Your translation finishes. |
| 💾 **Permanent & reversible** | Real file patching (not a fragile overlay) with automatic backups of every touched file. Uninstall = restore backups. |
| 🔍 **OCR overlay mode** | For games that can't be file-patched: a click-through overlay reads the screen and translates live. |
| 🌍 **Any language → any language** | Turkish is our first battlefield, but nothing is hardcoded. Source and target are your choice. |
| 🛡️ **Anti-cheat safe by design** | Games with kernel anti-cheat are never file-patched. No injection, no ban risk — OCR overlay only. |

### Battle-tested

Developed and verified in-game on real titles: story-heavy RPG Maker games (~95%+ dialogue coverage including image UI), KiriKiriZ visual novels with compiled scenarios, and even **Batman: Arkham Knight** — 18,000+ subtitle lines translated inside UE3 `.upk` packages using a size-exact patching technique we developed for this project.

### Free forever

No paywall, no premium tier. MIT-licensed, donations welcome. A translation tool should build bridges, not tollbooths.

### Legal & fair

Kizuna translates the game files **you own, on your machine**. It ships no game content, distributes no copyrighted assets, and touches nothing protected by anti-cheat.

## 🇹🇷 Türkçe

**Kizuna** (絆 — "bağ"), Windows için ücretsiz ve açık kaynaklı bir oyun çeviri launcher'ı. Oyununu seç, **Çevir**'e bas, kendi dilinde oyna. Eğitim videosu bu kadar.

Binlerce harika oyun hiçbir zaman yerelleştirilmiyor. Mevcut araçlar güçlü ama manuel: aracı öğren, motoru bul, çıkar, yamala, dua et. Kizuna'nın felsefesi farklı: **kullanıcı asla yöntem seçmez — sistem algılar ve uygular.**

### Farkı ne?

| | |
|---|---|
| 🖱️ **Tek tık, sıfır kurulum** | Kurulu oyunlarını (Steam, Epic, bağımsız) ve motorlarını otomatik tanır. Ayar dosyası yok, eklenti avı yok. |
| 🧩 **6+ motor desteği** | RPG Maker MV/MZ, Ren'Py, KiriKiri/KiriKiriZ (derlenmiş PSB senaryolar dahil), Unity, Unreal (.locres, .int, UE3 .upk) ve dahası yolda. |
| 🖼️ **Resimleri bile çevirir** | Menüye, HUD'a, butona gömülü yazılar? Kizuna resmi OCR'lar, orijinal yazıyı siler, senin dilinde yeniden çizer, dosyayı yeniden şifreler. Bunu otomatik yapan başka araç yok denecek kadar az — üstelik aynı tek tıkın içinde. |
| 🧠 **Gömülü yerel yapay zekâ** | Çevrimiçi çeviri takılır ya da bir satırı reddederse, gömülü yerel model (GPU hızlandırmalı) devralır. Çevirin yarım kalmaz. |
| 💾 **Kalıcı ve geri alınabilir** | Kırılgan overlay değil, gerçek dosya yaması — dokunulan her dosyanın otomatik yedeğiyle. Kaldırmak = yedekleri geri koymak. |
| 🔍 **OCR overlay modu** | Dosyası yamalanamayan oyunlar için: tıklamayı engellemeyen şeffaf katman ekranı okur, anlık çevirir. |
| 🌍 **Her dilden her dile** | İlk cephemiz Türkçe ama hiçbir şey Türkçeye çivili değil. Kaynak da hedef de senin seçimin. |
| 🛡️ **Anti-cheat'e saygılı** | Çekirdek seviyesi anti-cheat'li oyunlara asla dosya yaması yapılmaz. Enjeksiyon yok, ban riski yok — sadece OCR overlay. |

### Sahada test edildi

Gerçek oyunlarda, oyun içinde doğrulanarak geliştirildi: hikâye ağırlıklı RPG Maker oyunları (resim tabanlı arayüz dahil ~%95+ diyalog kapsaması), derlenmiş senaryolu KiriKiriZ görsel romanları ve hatta **Batman: Arkham Knight** — UE3 `.upk` paketlerinin içinde 18.000+ altyazı satırı, bu proje için geliştirdiğimiz bayt-dengi yama tekniğiyle çevrildi.

### Sonsuza dek ücretsiz

Paywall yok, premium paket yok. MIT lisanslı, bağışlar hoş karşılanır. Çeviri aracı köprü kurmalı, gişe değil.

### Yasal ve adil

Kizuna, **senin sahip olduğun oyunun dosyalarını, senin makinende** çevirir. Oyun içeriği dağıtmaz, telifli varlık paylaşmaz, anti-cheat korumalı hiçbir şeye dokunmaz.
